# TVOYAAPTEKA Data-ID Extractor

Получает `data-id` товаров по списку ссылок.

## Развертывание

1. Создать репозиторий на GitHub.
2. Загрузить файлы.
3. Открыть **Settings → Pages**.
4. Выбрать **Deploy from branch**.
5. Branch: `main`.
6. Сохранить.

Готово.

## Формат

Ввод:

https://www.tvoyaapteka.ru/catalog/.../товар1/
https://www.tvoyaapteka.ru/catalog/.../товар2/

Вывод:

[11076874]
[11076875]
